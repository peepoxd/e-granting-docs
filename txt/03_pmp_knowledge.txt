【Earned Value Management (EVM)】
─────────────────────────────────
• PV  (Planned Value)    = งบที่วางแผน ณ เวลานี้
• EV  (Earned Value)     = มูลค่างานที่ทำเสร็จจริง
• AC  (Actual Cost)      = ต้นทุนจริงที่ใช้ไป

สูตรสำคัญ:
┌─────────────────────────────────────────────────────────────────────────────┐
│ SV (Schedule Variance) = EV - PV   → บวก=เร็วกว่าแผน, ลบ=ช้ากว่าแผน       │
│ CV (Cost Variance)     = EV - AC   → บวก=ประหยัด, ลบ=เกินงบ               │
│ SPI (Schedule Index)   = EV / PV   → >1=เร็ว, <1=ช้า                      │
│ CPI (Cost Index)       = EV / AC   → >1=ประหยัด, <1=เกินงบ                │
│ EAC (Estimate at Completion) = BAC / CPI   → ประมาณการงบทั้งหมด           │
└─────────────────────────────────────────────────────────────────────────────┘


【Risk Response Strategies】
─────────────────────────────────
Negative Risks (Threats):
• AVOID    → เปลี่ยนแผนเพื่อหลีกเลี่ยง
• MITIGATE → ลดโอกาส/ผลกระทบ
• TRANSFER → โอนไปให้คนอื่น (ประกัน, Vendor)
• ACCEPT   → ยอมรับ (Active/Passive)

Positive Risks (Opportunities):
• EXPLOIT  → ทำให้เกิดแน่นอน
• ENHANCE  → เพิ่มโอกาส/ผลกระทบ
• SHARE    → แบ่งปันกับพันธมิตร
• ACCEPT   → ยอมรับถ้าเกิด

(ก่อตัว)   (ขัดแย้ง)   (ตกลง)    (ทำงานดี)     (ยุบทีม)

8. KEY FORMULAS (สูตรที่ต้องจำ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Communication Channels = n(n-1)/2   (n = จำนวนคน)
   ตัวอย่าง: 5 คน = 5(4)/2 = 10 channels

PERT Estimate = (O + 4M + P) / 6
   O = Optimistic, M = Most Likely, P = Pessimistic

Standard Deviation = (P - O) / 6

Float/Slack = LS - ES = LF - EF
   (เวลาที่ Activity ล่าช้าได้โดยไม่กระทบ Critical Path)

Conflict Resolution Techniques (เรียงตามประสิทธิภาพ):
1. Collaborate/Problem Solve  → หาทางออกร่วมกัน (Win-Win) ✓ ดีที่สุด
2. Compromise                 → ต่างฝ่ายต่างถอย
3. Smooth/Accommodate         → ยอมให้อีกฝ่าย
4. Force/Direct               → บังคับ (ใช้เมื่อเร่งด่วน)
5. Withdraw/Avoid             → หนี/หลีกเลี่ยง ✗ แย่ที่สุด
