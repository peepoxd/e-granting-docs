ระบบสารสนเทศสนับสนุนโครงการ สสส.
ThaiHealth Project Management Information System (TPMIS)
============================================================

โครงสร้างระบบ
-------------

ผู้ใช้งาน 5 กลุ่ม:
- ภาคีเครือข่าย (ยื่นข้อเสนอ, ส่งผลงาน)
- เจ้าหน้าที่ สสส. (ประเมิน, ติดตาม)
- ผู้อนุมัติ (อนุมัติโครงการ/งบ)
- ฝ่ายการเงิน (เบิกจ่าย, ตรวจหลักฐาน)
- ผู้บริหาร (Dashboard, รายงาน)

กระบวนการหลัก:
พัฒนาข้อเสนอ -> อนุมัติโครงการ -> เบิกจ่ายงวด -> ส่งผลงาน -> ปิดโครงการ

ระบบสนับสนุน:
- ฐานข้อมูลกลาง
- ระบบแจ้งเตือน (Email/LINE)
- ระบบรายงาน + Dashboard
- เชื่อมต่อ GFMIS


Components หลัก
---------------

Module                  | หน้าที่                    | ผู้ใช้งาน
------------------------|---------------------------|---------------------------
Proposal Management     | รับ-ประเมินข้อเสนอ         | ภาคี, เจ้าหน้าที่
Approval Management     | อนุมัติโครงการ/งบ          | ผู้อนุมัติ
Financial Management    | เบิกจ่ายตามงวด            | การเงิน
Delivery Management     | ติดตาม/ประเมินผลงาน       | เจ้าหน้าที่
Closure Management      | สรุป/ปิดโครงการ           | เจ้าหน้าที่, ผู้บริหาร


Key Features
------------
- E-Proposal: ยื่นข้อเสนอออนไลน์ แนบเอกสารดิจิทัล
- Workflow Automation: อนุมัติอัตโนมัติตามลำดับขั้น
- Financial Tracking: ติดตามเบิกจ่าย Real-time เชื่อม GFMIS
- Progress Monitoring: Dashboard ติดตามความก้าวหน้า
- Notification: แจ้งเตือนผ่าน Email/LINE


Technology Stack
----------------
Frontend: React.js
Backend: Node.js, REST API
Database: PostgreSQL
Cloud: G-Cloud
Security: OAuth 2.0, 2FA


Expected Benefits
-----------------
- ลดเวลาดำเนินการ 40%, ลดเอกสารกระดาษ 80%
- ติดตามสถานะ Real-time, มี Audit Trail
- ภาคีเข้าถึงระบบได้ 24/7
