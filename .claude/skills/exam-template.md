# Exam Template - ข้อสอบ PM IT สสส.

## ข้อ 1: ออกแบบระบบ (System Design)

### โครงสร้างการเขียน (เต็ม A4)

| ส่วน | สัดส่วน | เนื้อหา |
|------|---------|---------|
| หัวข้อ + Diagram | 30% | ชื่อระบบ + Architecture Diagram |
| ความเป็นมา/วัตถุประสงค์ | 10% | ปัญหา, เป้าหมาย |
| องค์ประกอบระบบ | 20% | Frontend, Backend, Database, Integration |
| ฟังก์ชันหลัก | 15% | ตารางโมดูล/ฟังก์ชัน |
| เทคโนโลยี | 10% | Tech Stack |
| แผนดำเนินงาน | 10% | Phase 1-5 |
| ประโยชน์ | 5% | Bullet points |

```
   - รองรับกระบวนการ: พัฒนาข้อเสนอ → อนุมัติ → เบิกเงิน → ส่งงาน → ปิดโครงการ
   - แก้ปัญหา: [ระบุปัญหาปัจจุบัน]

       - API Gateway: Kong/AWS API Gateway

       - Redis: Caching

       - เชื่อมต่อ e-GP, GFMIS, e-Budget

4. เทคโนโลยีที่ใช้

   - Security: OAuth 2.0, JWT, SSL/TLS, WAF
   - DevOps: Docker, Kubernetes, CI/CD

5. แผนการดำเนินงาน
   Phase 1: Analysis & Design      → Requirement, System Design
   Phase 2: Development            → Coding, Unit Test
   Phase 3: Testing & UAT          → Integration Test, User Acceptance
   Phase 4: Deployment & Training  → Go-Live, Knowledge Transfer
   Phase 5: Support & Maintenance  → Bug Fix, Enhancement

6. ประโยชน์ที่คาดว่าจะได้รับ
   ✓ ลดเวลาการทำงานซ้ำซ้อน        ✓ Single Source of Truth

   ✓ ลดการใช้กระดาษ              ✓ เพิ่มความโปร่งใส
================================================================================
```

## เทคนิคการเขียน

### ASCII Diagram Symbols
| Symbol | ความหมาย |
|--------|----------|
| `┌─┐` `└─┘` | กล่อง/Box |
| `→` `←` `↑` `↓` | ลูกศร |
| `▶` `◀` `▲` `▼` | ลูกศรทึบ |
| `○` | เริ่มต้น (Start) |
| `◎` | สิ้นสุด (End) |
| `◇` | ตัดสินใจ (Decision) |
| `[ ]` | กิจกรรม (Activity) |

### ระบบราชการที่ต้องอ้างอิง
- **e-GP** - ระบบจัดซื้อจัดจ้างภาครัฐ
- **GFMIS** - ระบบการเงินการคลัง
- **e-Budget** - ระบบงบประมาณ
- **PMQA** - ระบบประเมินคุณภาพ

### กระบวนการหลัก สสส.
```
พัฒนาข้อเสนอ → อนุมัติ → เบิกเงิน → ส่งงาน → ปิดโครงการ
```
