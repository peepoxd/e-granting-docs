# PMP Knowledge Reference

> Project Management Professional (PMBOK 7th Edition)

## 1. Project Management Principles (12 ข้อ)

| # | Principle | ความหมาย |
|---|-----------|----------|
| 1 | Be a diligent, respectful, and caring steward | เป็นผู้ดูแลที่ขยัน ให้เกียรติ และใส่ใจ |
| 2 | Create a collaborative team environment | สร้างทีมที่ร่วมมือกัน |
| 3 | Effectively engage with stakeholders | มีส่วนร่วมกับ Stakeholder อย่างมีประสิทธิภาพ |
| 4 | Focus on value | มุ่งเน้นคุณค่า |
| 5 | Recognize, evaluate, and respond to system interactions | ตอบสนองต่อปฏิสัมพันธ์ของระบบ |
| 6 | Demonstrate leadership behaviors | แสดงพฤติกรรมความเป็นผู้นำ |
| 7 | Tailor based on context | ปรับแต่งตามบริบท |
| 8 | Build quality into processes and deliverables | สร้างคุณภาพในกระบวนการและผลลัพธ์ |
| 9 | Navigate complexity | จัดการความซับซ้อน |
| 10 | Optimize risk responses | ปรับการตอบสนองความเสี่ยงให้เหมาะสม |
| 11 | Embrace adaptability and resiliency | ยอมรับการปรับตัวและความยืดหยุ่น |
| 12 | Enable change to achieve the envisioned future state | ส่งเสริมการเปลี่ยนแปลงเพื่อบรรลุเป้าหมาย |

## 5. Key Tools & Techniques

### WBS (Work Breakdown Structure)
- แตกงานใหญ่ → งานย่อย → Work Packages
- ใช้ 100% Rule (งานย่อยรวมกัน = งานหลัก)

### RACI Matrix
| Role | ความหมาย |
|------|----------|
| **R** - Responsible | ผู้รับผิดชอบทำ |
| **A** - Accountable | ผู้รับผิดชอบผล (มีได้คนเดียว) |
| **C** - Consulted | ผู้ให้คำปรึกษา |
| **I** - Informed | ผู้รับทราบ |

### Earned Value Management (EVM)

**ค่าพื้นฐาน:**
- PV (Planned Value) = งบที่วางแผน ณ เวลานี้
- EV (Earned Value) = มูลค่างานที่ทำเสร็จจริง
- AC (Actual Cost) = ต้นทุนจริงที่ใช้ไป

**สูตรสำคัญ:**
| สูตร | ความหมาย | การแปลผล |
|------|----------|----------|
| SV = EV - PV | Schedule Variance | + เร็ว, - ช้า |
| CV = EV - AC | Cost Variance | + ประหยัด, - เกินงบ |
| SPI = EV / PV | Schedule Index | >1 เร็ว, <1 ช้า |
| CPI = EV / AC | Cost Index | >1 ประหยัด, <1 เกินงบ |
| EAC = BAC / CPI | Estimate at Completion | ประมาณการงบทั้งหมด |

### Risk Response Strategies

**Negative Risks (Threats):**
| Strategy | วิธีการ |
|----------|---------|
| Avoid | เปลี่ยนแผนเพื่อหลีกเลี่ยง |
| Mitigate | ลดโอกาส/ผลกระทบ |
| Transfer | โอนไปให้คนอื่น (ประกัน, Vendor) |
| Accept | ยอมรับ (Active/Passive) |

**Positive Risks (Opportunities):**
| Strategy | วิธีการ |
|----------|---------|
| Exploit | ทำให้เกิดแน่นอน |
| Enhance | เพิ่มโอกาส/ผลกระทบ |
| Share | แบ่งปันกับพันธมิตร |
| Accept | ยอมรับถ้าเกิด |

### Tuckman's Team Development
```
Forming → Storming → Norming → Performing → Adjourning
(ก่อตัว)  (ขัดแย้ง)  (ตกลง)   (ทำงานดี)   (ยุบทีม)
```

## 6. Agile vs Waterfall

| หัวข้อ | Waterfall | Agile |
|--------|-----------|-------|
| Requirement | ชัดเจนตั้งแต่แรก | เปลี่ยนได้ตลอด |
| Delivery | ท้ายโครงการ | ทุก Sprint (2-4 สัปดาห์) |
| Customer Feedback | ท้ายโครงการ | ทุก Sprint Review |
| Documentation | มาก, Formal | น้อย, พอเพียง |
| Change | ยาก, ต้อง Change Request | ยินดีรับ |
| Team | แยกตาม Function | Cross-functional |
| เหมาะกับ | ภาครัฐ, Fixed Scope | Startup, Innovation |

### Scrum Framework
- **Roles:** Product Owner, Scrum Master, Dev Team
- **Events:** Sprint Planning, Daily Standup, Sprint Review, Retrospective
- **Artifacts:** Product Backlog, Sprint Backlog, Increment

## 8. Key Formulas

| สูตร | ใช้เมื่อ |
|------|---------|
| `Communication Channels = n(n-1)/2` | หาจำนวนช่องทางสื่อสาร (n = จำนวนคน) |
| `PERT = (O + 4M + P) / 6` | ประมาณเวลา (O=Optimistic, M=Most Likely, P=Pessimistic) |
| `Standard Deviation = (P - O) / 6` | หาค่าเบี่ยงเบน |
| `Float = LS - ES = LF - EF` | เวลาที่ล่าช้าได้โดยไม่กระทบ Critical Path |

## 9. PM Soft Skills

| Skill | รายละเอียด |
|-------|------------|
| Leadership | นำทีม, สร้างแรงบันดาลใจ, ตัดสินใจ |
| Communication | สื่อสารชัด, ฟังเป็น, Presentation |
| Negotiation | เจรจาต่อรอง, Win-Win |
| Problem Solving | วิเคราะห์ปัญหา, หา Root Cause |
| Conflict Management | จัดการความขัดแย้ง |
| Time Management | จัดลำดับความสำคัญ, Delegation |
| Emotional Intelligence | เข้าใจอารมณ์ตนเอง/ผู้อื่น |

### Conflict Resolution (เรียงตามประสิทธิภาพ)
1. **Collaborate** → หาทางออกร่วมกัน (Win-Win) ✓ ดีที่สุด
2. **Compromise** → ต่างฝ่ายต่างถอย
3. **Smooth/Accommodate** → ยอมให้อีกฝ่าย
4. **Force/Direct** → บังคับ (ใช้เมื่อเร่งด่วน)
5. **Withdraw/Avoid** → หนี/หลีกเลี่ยง ✗ แย่ที่สุด
