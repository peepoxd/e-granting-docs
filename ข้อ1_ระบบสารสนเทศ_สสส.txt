================================================================================
                    รายละเอียด MODULES ตาม Grant Lifecycle
================================================================================

┌────────────────────┬─────────────────────┬─────────────────┬────────────────────────────────────┐
│ Module             │ กระบวนการ           │ ผู้รับผิดชอบ     │ ฟังก์ชันหลัก                        │
├────────────────────┼─────────────────────┼─────────────────┼────────────────────────────────────┤
│ 1. จัดทำข้อเสนอ     │ พัฒนาข้อเสนอโครงการ  │ ภาคี+นักวิชาการ  │ กรอกข้อมูล, วัตถุประสงค์, กิจกรรม,   │
│                    │                     │                 │ งบประมาณ, แนบเอกสาร               │
├────────────────────┼─────────────────────┼─────────────────┼────────────────────────────────────┤
│ 2. คัดกรอง/กลั่นกรอง │ ประเมินความเหมาะสม   │ นักวิชาการ       │ คัดกรองขั้นต้น, กลั่นกรองวิชาการ,    │
│                    │                     │                 │ บันทึกงวดเงิน                      │
├────────────────────┼─────────────────────┼─────────────────┼────────────────────────────────────┤
│ 3. อนุมัติโครงการ   │ พิจารณาอนุมัติ       │ ผู้มีอำนาจ       │ อนุมัติ/ไม่อนุมัติ/ส่งแก้ไข,         │
│                    │                     │                 │ กำหนดเงื่อนไข                      │
├────────────────────┼─────────────────────┼─────────────────┼────────────────────────────────────┤
│ 4. ทำสัญญา         │ จัดทำสัญญารับทุน     │ ศูนย์สัญญา+ภาคี  │ ตรวจคุณสมบัติ, ลงนามอิเล็กทรอนิกส์   │
│                    │                     │                 │ (E-Signature)                     │
├────────────────────┼─────────────────────┼─────────────────┼────────────────────────────────────┤
│ 5. เบิกจ่าย/ส่งงาน  │ บริหารโครงการ       │ ภาคี+นักวิชาการ  │ ขอเบิกงวดเงิน, ส่งรายงานความก้าวหน้า, │
│                    │                     │                 │ ตรวจรับงาน                        │
├────────────────────┼─────────────────────┼─────────────────┼────────────────────────────────────┤
│ 6. ปิดโครงการ      │ สรุปและปิดโครงการ    │ ศูนย์สัญญา       │ ตรวจครุภัณฑ์, สรุปผล, อนุมัติปิด     │
└────────────────────┴─────────────────────┴─────────────────┴────────────────────────────────────┘

================================================================================
                              KEY FEATURES
================================================================================

├── E-Proposal
│   └── ยื่นข้อเสนอออนไลน์, Auto-save, แนบไฟล์หลายรูปแบบ
│
├── Multi-level Approval
│   └── Workflow อนุมัติหลายขั้น (คัดกรอง → กลั่นกรอง → อนุมัติ)
│
├── E-Contract & E-Signature
│   └── ลงนามสัญญาอิเล็กทรอนิกส์, ลดเวลาจัดส่งเอกสาร
│
├── Installment Tracking
│   └── เบิกจ่ายเป็นงวด, ตรวจสอบรายงานก่อนเบิกงวดถัดไป
│
├── Progress Monitoring
│   └── ติดตามความก้าวหน้า, รายงานสถานะ Real-time
│
└── PDPA Compliance
    └── รองรับ พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล
